# LAN Sync - Obsidian 局域网同步插件

一款类似 LocalSend 的 Obsidian 插件，让你在局域网内的设备间自动同步仓库、分享笔记，无需联网，数据不经任何服务器。

## 功能亮点

- **自动发现设备**：插入即用，局域网内的设备自动出现在列表中（桌面端）
- **一键绑定同步**：设备间验证码安全绑定，后台自动同步仓库内容
- **笔记分享**：右键菜单一键分享笔记到任意局域网设备
- **传输加密**：所有文件传输自动 AES-256-GCM 加密，安全可靠
- **大文件支持**：大文件自动分片传输，稳定高效
- **历史副本保护**：同步覆盖前自动备份，可随时恢复
- **实时通信**：基于 WebSocket 长连接，设备状态即时感知
- **同步收发**：双向同步收发，保持绑定双方数据一致
- **同步历史**：记录每次同步的详细信息，支持查看发送/接收的文件清单
- **多语言支持**：简体中文、English、繁体中文、法语、日语、韩语

## 支持平台

| 功能 | 桌面端 (Win/Mac/Linux) | 移动端 (Android/iOS) |
|------|:---:|:---:|
| 自动发现设备 | ✅ | ❌ |
| 手动连接设备 | ✅ | ✅ |
| 同步收发 | ✅ | ✅ |
| 分享笔记 | ✅ | ✅ |
| 接收分享确认 | ✅ | ✅ |

> 移动端由于系统限制，需手动输入桌面设备的 IP 地址进行连接。

## 安装方法

1. 将以下三个文件复制到 Obsidian 仓库的 `.obsidian/plugins/lan-sync/` 目录：
   - `main.js`
   - `manifest.json`
   - `styles.css`
2. 打开 Obsidian → **设置** → **第三方插件** → 启用 "LAN Sync"

## 使用指南

### 第一步：配置设备别名

打开插件设置，为你的设备设置一个有辨识度的别名（如"小明的 MacBook"），方便在局域网中被识别。

### 第二步：发现设备

- **桌面端**：勾选「可被发现」开关，设备会自动出现在列表中
- **移动端**：在设置页「手动添加桌面设备」区域，输入桌面设备的 IP 地址和端口

也可以通过命令面板搜索「查看局域网设备」打开设备列表。

### 第三步：绑定设备

1. 在设备列表中点击目标设备的别名
2. 发起方屏幕会显示一个 6 位验证码
3. 目标方输入该验证码完成身份验证
4. 绑定关系自动建立，当前仓库纳入同步范围

同一设备可参与多个绑定组，每个绑定组包含 2 台设备。

### 第四步：自动同步

绑定完成后，插件会按设定间隔（默认 15 分钟）自动检查并同步仓库变更。同步规则：

- 以文件的**最新修改时间**为准
- 同步前自动为本地文件创建历史副本（默认保留 5 份），可随时恢复
- 文件的删除操作也会同步到其他绑定设备

### 解绑设备

在设置页面的已绑定设备列表中，可随时解除与某台设备的绑定。解绑后双方将不再自动同步，但各自的仓库文件不受影响。

### 同步历史

在设置页面的「同步历史」区域，可以查看每次同步的详细记录，包括发送/接收的文件列表及变更类型（新增/修改/删除）。

### 分享笔记

在任意笔记文件上 **右键** → 选择「分享到设备...」：

- 对方会收到弹窗确认，可选择：
  - 接收
  - 另存为（自定义保存路径）
  - 拒绝
  - 加入黑名单

连续拒绝同一设备的分享后，系统会自动将其拉黑（阈值可配置）。

## 命令列表

| 命令 | 说明 |
|------|------|
| 查看局域网设备 | 浏览并绑定局域网内的其他设备 |
| 立即同步 | 手动触发一次仓库同步 |

## 设置项说明

| 设置 | 默认值 | 说明 |
|------|--------|------|
| 同步间隔 | 15 分钟 | 自动同步的时间间隔 |
| 历史副本数量 | 5 | 每个文件保留的历史副本数 |
| 历史副本目录 | `.obsidian/.lan-sync-history` | 历史副本保存路径 |
| 自动拉黑阈值 | 3 次 | 连续拒绝分享后自动拉黑 |
| 分片大小 | 10MB | 大文件分片传输的每片大小 |

## 状态栏（桌面端）

桌面端 Obsidian 底部状态栏会显示当前同步状态图标，点击可弹出快捷菜单，支持手动同步、查看设备、打开设置等操作。
